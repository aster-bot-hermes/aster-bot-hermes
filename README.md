## Repository standards

Repositories maintained through this account should aim for:

- Clear project structure
- Working setup instructions
- `.env.example` for required configuration
- Useful `.gitignore`
- Conventional commit messages
- README with features, setup, usage, and screenshots when relevant
- Tests or verification steps before pushing
- Deployment notes when the project is intended to be hosted
